# Мост L2↔L7: Со-эволюционное знание

> Навык: создание знаний, которых нет ни у одного участника по отдельности.

## Зачем

Без этого моста знания извлекаются из наблюдений (ошибок, успехов). С мостом — знания РОЖДАЮТСЯ в совместном мышлении. Инсайт "проактивный intensity = если знал, зачем делал?" — пример: ни агент, ни собеседник не пришли бы к нему в одиночку.

**Ценность:** Качественно иные знания. Совместные инсайты глубже, потому что объединяют формализацию агента + интуицию собеседника.

## Цикл

```
L2 (Knowledge)              L7 (Co-Cognition)           L2 (Knowledge)
┌──────────────┐            ┌──────────────┐            ┌──────────────┐
│ База знаний  │──контекст→ │ Совместное   │──инсайт──→│ Новое знание │
│ = общая      │            │ мышление     │            │ origin:      │
│ почва        │            │              │            │ co-cognition │
└──────────────┘            └──────────────┘            └──────────────┘
       ↑                                                       │
       └────────── обогащённая база → глубже мыслим ───────────┘
```

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Знания из ошибок и наблюдений | Знания из совместного мышления |
| Агент извлекает, собеседник валидирует | Оба генерируют, оба валидируют |
| Linear accumulation | Спиральный рост (больше знаний → глубже со-мышление → ещё больше знаний) |

## Реализация

1. **В /learn и /retro:** поле `origin: solo|co-cognition` в frontmatter. Если знание родилось в обсуждении (а не из ошибки/наблюдения) — пометить
2. **В /knowledge-audit:** отдельная метрика `co-cognition_ratio` — какая доля знаний порождена совместно? Тренд должен расти
3. **В правилах:** при со-мышлении (L7 активен) — активнее записывать инсайты, не ждать /learn
