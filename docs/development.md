## Гочи проекта (Claude их не угадает)

- **Среда исполнения Bash-инструмента — zsh, не bash.** Не полагаться на bash-семантику
  в inline-командах; парсинг — `jq`/`awk`; сложное — писать в файл (`pattern-shell-portability`).
- **Вынос sourced-под-библиотеки** (`*-lib.sh`, подключаемой через `${BASH_SOURCE[0]%/*}`):
  `install.sh` копирует все `hooks/*.sh` сам, НО фиксированные списки
  (`backfill-replay-one.sh`) и симлинк-фикстуры тестов дополнять **вручную** — иначе
  тихая поломка в изолированном окружении (`case-2026-06-20-hook-dependency-install-drift`).
- **Монолит без своего теста** → сперва характеризующий тест (сквозной прогон,
  детерминизм через фикс. session-id), потом разрез. Резать готовые функции; встроенную
  оркестрацию (мутирует глобальные, побочные эффекты) — не выносить.
- **Числа/статусы/seed — НЕ править руками** (см. таблицу механизмов ниже).
- **Перед задачей** — `mcp__claudsoul__search_knowledge` по ключевым словам
  (семантический поиск находит то, что keyword-активатор пропускает —
  `case-2026-04-16-ignored-own-knowledge-base`).

## Где правило = механизм (канон D5: механизм > текст)

| Что должно держаться | Механизм |
|----------------------|----------|
| Числа хуков/скиллов/доменов в доках | `scripts/count-stats.sh` + `test_doc_counts.py` |
| Seed-база из рабочей | `scripts/regen-seed.py --check` + `test_seed_integrity.py` |
| Статусы мостов = реальности | `test_bridge_status_consistency.py` |
| Граф доменов без висячих/сирот | `test_domain_graph_integrity.py` |
| Внутренние ссылки доков | `test_doc_links.py` |
| Семья из 5 доков на бамп версии | хук `docs-family-check.sh` |
| Захват знаний по ходу | хук `knowledge-capture-reminder.sh` → `_drafts/` |
| 2+ ошибки подряд → стоп + черновик | хук `error-tracker.sh` |

## Обязательные шаги при добавлении

- **Хук** → тест в `hooks/tests/` + регистрация в `install.sh` (`HOOKS_CONFIG`) + если
  source-ит под-библиотеку, см. гочу выше + синхронизировать число (`count-stats`).
- **Скилл** → контракт `docs/skill-contract.md`; таблицы в README авто-генерируются
  (`scripts/regen-readme-skills.sh`), не править руками.
- **Знание** → формат v0.2 (`knowledge/META.md`); универсальные — в seed через `regen-seed.py`.

## Журналы

- Каждое изменение → `CHANGELOG.md`; каждая сессия → `SESSION.md`; архитектурные
  решения → `docs/decisions.md` (ADR).
